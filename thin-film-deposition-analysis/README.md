
# Thin-Film Deposition Process Analysis

## 1. Project Overview
This project focuses on understanding thin-film deposition parameters and their relationship with film properties using Python-based data analysis.

The project aims to develop data-analysis skills relevant to semiconductor process engineering.

## 2. Objectives
- Understand key thin-film deposition parameters.
- Organize and analyze deposition data using Python.
- Visualize relationships between process parameters and film thickness.
- Identify data limitations and opportunities for further experiments.

## 3. Parameters of Interest
- Deposition power
- Working pressure
- Deposition time
- Substrate temperature
- Film thickness

## 4. Tools and Technologies
- Python
- Jupyter Notebook
- pandas
- NumPy
- Matplotlib

## 5. Methodology
1. Collect and organize available deposition data.
2. Inspect and clean the dataset.
3. Perform exploratory data analysis.
4. Generate plots to investigate parameter relationships.
5. Interpret observations and document limitations.

## 6. Results
Results and visualizations will be added after the data analysis is completed.

## 7. Limitations
Conclusions will be limited to the available data. Synthetic datasets, if used for practice, will be clearly identified and kept separate from experimental measurements.

## 8. Future Work
- Analyze additional deposition runs.
- Investigate film thickness uniformity when spatial measurements are available.
- Explore statistical models after sufficient data is collected.
- Document reproducible analysis in a Jupyter Notebook.
